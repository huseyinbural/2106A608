Deep Learning Studio 🧠✨
This application is a simple GUI designed for you to explore Deep Learning models and interact 
with their fundamental structures. With MLP, CNN, and RNN tabs, you can quickly glance at 
different model types!

🌟 Tabs & What They Offer
Here's a quick rundown of the main tabs in our app:

MLP (Multi-Layer Perceptron) 📊: The heart of basic neural networks! See how data flows from input to output layers.
CNN (Convolutional Neural Network) 📸: Perfect for images! Discover the magic of convolutional layers and feature extraction.
RNN (Recurrent Neural Network) 📜: Tailor-made for sequential data and time series! Witness the power of memory cells.

---------------------------------------------------------------------------------------------------------------
Each has same easy to use architecture. One can load precreated .h5 models (with configure) or can
create their own. Once created, it can also be saved for future usages. 

First select dataset, you can split your dateset or can go with default split. Right after selecting 
relative paramters, hit Train.
